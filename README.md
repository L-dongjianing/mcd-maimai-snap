# 🍔 麦麦拍一下 · maimai-paiyixia

> 把你看到的麦当劳，变成你看得懂、知道怎么参与的麦当劳。

「麦麦拍一下」不是一个"识别图片的工具"，而是一个**懂麦当劳的看图搭子**。你负责把看到的发给它，它负责把"这是什么"往前多走一步，变成"这跟我有什么关系，我怎么参与"。

很多消费冲动，停在了一张图上：路过门店看到联名海报不知道怎么拿周边；朋友群里发了张活动图不知道今天还能不能用；刷到别人晒的餐盘叫不出名字。截图收藏了，往往也就忘了。麦麦拍一下接住的，就是这个**"感兴趣，但还没行动"的瞬间**。

## ✨ 一个入口，三种发现

| 场景 | 你发的图 | 它做的事 |
| --- | --- | --- |
| 🎟️ **拍海报，发现玩法** | 联名海报 / 活动宣传图 | 不只读出活动名，而是讲清：什么时候、重点是什么、参加要什么条件（对照官方活动日历核验） |
| 🍟 **拍餐品，发现同款** | 朋友的餐盘 / 网上的美食图 | 给出可能的餐品，帮你确认，再对照所选门店找同款或在售替代，并算好价格 |
| 🎫 **拍优惠，发现关系** | 优惠截图 / 券面图 | 拆开使用条件，对照你的卡包和所选门店，区分"图里说有优惠"和"你现在实际可以用" |

拍完得到的不是一篇解释，而是一张 **「麦麦发现卡」**：一句人话回应最关心的问题 + 我看到了什么 / 和你有什么关系 / 接下来怎么做，附查询时间戳。

**诚实是产品的底线**：所有结论基于麦当劳官方 MCP 工具的实时返回；查不清就说清楚哪里没查清，绝不让卡片为了好看而编出优惠。分享出去的卡片保留查询时间，不让它变成下一张误导人的旧截图。

## 🎯 目标用户

- 被"一张图"勾起兴趣、但懒得翻菜单翻活动页的**普通消费者**
- 群里收到活动图/优惠截图，需要快速判断"跟我有没有关系"的**社交转发者**
- 想给朋友安利"这个怎么玩"的**麦门爱好者**

## 🚀 安装方法

### 前置条件

- 一个麦当劳中国 MCP Token（[申请指南](https://github.com/M-China/mcd-mcp-server)）
- WorkBuddy 桌面版

### 第一步：配置麦当劳 MCP 连接器

在 WorkBuddy 左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，填入（替换为你自己的 Token）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

保存后启用 `mcd-mcp`。

### 第二步：安装麦麦拍一下技能

将 `skill/maimai-paiyixia/` 整个目录复制到 `~/.workbuddy/skills/`（或通过 WorkBuddy 技能导入 `dist/maimai-paiyixia.zip`），重启会话即可生效。

### 第三步：发一张图试试

在对话框直接发送任意麦当劳相关图片 + 一句话（见下方示例）。

## 💬 使用示例

**拍海报：**
> [发一张联名海报图] 这个怎么参加？
> → 麦麦发现卡：官方日历已收录该活动，10.24–11.7 进行中，到店买联名套餐即可参与，抽奖入口在 App 卡包……

**拍餐品：**
> [发一张餐盘照片] 我也想吃这个！
> → 麦麦发现卡：图里大概率是「不素之霸」，你常去的××店现在有售，套餐计算价 ¥38.5，回复"就它了"我帮你算好到店自取价……

**拍优惠：**
> [发一张优惠截图] 我也能用吗？
> → 麦麦发现卡：图里说第二份半价，但图面日期已过、你的卡包里没有它——不过现在能领一张同款券，要领吗……

更多端到端示例见 [examples/usage-examples.md](examples/usage-examples.md)。

## 🏗️ 技术设计要点

- **一个入口，场景路由**：无需用户选择模式，Skill 先判断图片属于活动/餐品/优惠，再走对应 MCP 调用链（详见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)）。
- **多轮延续**：同一话题追问（"两个人去合适吗"）沿用已确认的场景与门店，不让用户重新发图重新描述。
- **时间戳守卫**：渲染器缺少 `queryTime` 时拒绝出卡——没有查询时间的发现卡会误导转发者。
- **只讲查到的事实**：图上文字只能转述（标注"图里说"），结论必须来自 MCP 官方返回；查不到写"暂未查到"。
